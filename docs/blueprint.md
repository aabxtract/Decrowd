# **App Name**: DeCrowd

## Core Features:

- Campaign Creation: Allow users to create campaigns with a title, description, funding goal, and deadline, stored on-chain.
- Campaign Listing & Details: Display active campaigns with key details like funding goal, amount raised, and deadline countdown.
- Wallet Donation: Enable users to connect their wallets and donate to active campaigns.
- Smart Contract Logic: Enforce campaign rules on-chain, including deadline enforcement, creator withdrawals upon goal achievement, and contributor refunds if the goal is not met.
- Withdrawal/Refund Mechanism: Allow campaign creators to withdraw funds if the goal is met, or contributors to claim refunds if the goal is not met.
- Success and Error Display: Display success and error messages clearly during donation, withdrawal, and refund processes.
- Campaign Description Summarization: Utilize AI to generate a brief summary of each campaign description for quick viewing in campaign listings.

## Style Guidelines:

- Primary color: Vibrant blue (#3498DB) for trust and innovation, evoking the transparent and forward-thinking nature of blockchain; darker tones can subtly shift toward purple for a modern feel.
- Background color: Light gray (#ECF0F1) to ensure content is clearly readable and contributes to a clean, modern look.
- Accent color: Analogous bright green (#2ECC71), symbolizing achievement, growth, and the successful attainment of fundraising goals; serves to highlight key interactive elements, CTAs and confirmations.
- Headline font: 'Space Grotesk' sans-serif font for a computerized, techy feel, used for headlines and campaign titles.
- Body font: 'Inter' grotesque-style sans-serif font for body text in campaign descriptions and UI elements.
- Use simple, modern icons for campaign categories and actions (donate, withdraw, refund).
- Clean, grid-based layout for campaign listings, ensuring a responsive design for mobile and desktop.
- Subtle animations on campaign progress bars and button interactions to provide feedback and enhance UX.
